# Zenote product scope

## Current: MVP / V1

- ChatGPT-style AI chat on responsive desktop and mobile interfaces.
- Authentication and account access.
- Conversation history and messages.
- Streaming AI responses.
- Multiple models or providers with clear model selection.
- Image and file input only when the selected model supports it.
- Markdown and code rendering in chat responses.
- Usage tracking and enforceable limits.
- Free, Plus, and Pro plan concepts, PHP pricing, subscriptions, and Philippine-friendly payment methods where supported by the payment provider.

## Not in scope

- Autonomous or multi-agent systems.
- Workflows, automations, and task orchestration.
- RAG, vector databases, document knowledge bases, or Notion-like workspaces.
- Enterprise collaboration, organizations, team administration, or advanced permissions.
- Unrelated productivity tools.

## Later

Only consider features after the core chat experience is reliable, measured, and financially sustainable. Prioritize using evidence from user needs, provider capabilities, payment support, and actual usage economics; do not treat any later idea as committed work.
